The principles

Make the right thing easy to use.

Good foundations disappear into the experience. They give every decision a clear purpose.

01

Clarity first

Use hierarchy, meaningful copy, and generous space so people always know where they are.

02

Progressive by default

Start with native HTML, enhance when it earns its place, and keep the core experience resilient.

03

Kind to every device

Responsive layouts, visible focus, reduced motion, and fast loading are product features.

FAQ

Start small. Stay intentional.

Does this need a framework?

No. The starter is intentionally built with platform features so it can be opened directly in a browser.

Is the layout responsive?

Yes. The layout uses fluid type, flexible grids, and mobile-first breakpoints without fixed-height content areas.

What should I change first?

Replace the content and design tokens in styles.css, then keep the semantic structure and interaction patterns.
